# GIR Invaders Grim

A static Dark War: Survival alliance dashboard based on the DGF layout. Open index.html to preview the template.

The Grim Command homepage includes Coral Tower Siege side panels on wide screens. The Season guide, Tips, Calculators and Planner share the green-and-gold theme. The Black Gold planner has desert artwork and its own battlefield diagram. GIR has its own browser storage for the planner roster and language setting.

For GitHub Pages, push this folder as a new repository and configure Pages to use main and / (root).
